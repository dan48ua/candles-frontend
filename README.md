# Candles E-Commerce Store (Frontend)

A modern, responsive e-commerce frontend built for a candle store. This project demonstrates scalable React architecture, global state management, and seamless API integration.

## Core Features
* **Shopping Cart & Checkout:** Managed via Redux Toolkit (`basketSlice.ts`, `order.service.ts`).
* **User Authentication:** Secure login and session handling (`authSlice.ts`).
* **Product Catalog:** Dynamic routing and rendering of candle interfaces.

## Tech Stack
* **Framework:** Next.js / React
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **State Management:** Redux Toolkit
* **Containerization:** Docker

## Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)
